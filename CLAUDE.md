# ASMS Backend — Developer Conventions

## Handler / Service Split Convention (since v2.0.0)

All API operations follow a two-class pattern per resource:

### Handler (`com.asms.handler.*Handler`)
- Annotated `@Component`
- Implements exactly one `*ApiDelegate` interface (generated by the contract artifact)
- **Thin REST adapter only** — passes DTOs straight to the service and returns the result
- Constructor-injects the corresponding `*Service`
- No business logic, no repository access, no generated DTO manipulation beyond pass-through

### Service (`com.asms.service.*Service`)
- Annotated `@Service`
- **Does NOT implement any `*ApiDelegate` interface**
- Contains all business logic: validation, persistence, event production, policy enforcement
- Constructor-injects repositories, mappers, and other services
- May use generated OpenAPI DTOs as method parameters/return types (these are value objects, not HTTP concerns)

### Example

```
POST /users
  → UsersApiController (contract JAR)       — generated, HTTP routing only
  → UsersHandler implements UsersApiDelegate — REST adapter, @Component
  → UsersService                             — domain logic, @Service
  → UserRepository                           — Spring Data JPA
```

### ArchUnit guard

`ArchitectureTest` enforces:
- No class in `com.asms.service` implements `*ApiDelegate`
- All `@Component` classes named `*Handler` reside in `com.asms.handler`
- No class in `com.asms.handler` directly depends on `com.asms.repository`

**Do not regress this pattern.** If you add a new API resource, create both a `*Handler` and a `*Service`.

## Package Structure

```
com.asms/
  AsmsApplication.java          — main entry point (root package for component scan)
  handler/                      — REST adapters (implements *ApiDelegate)
  service/                      — domain business logic
  repository/                   — Spring Data JPA interfaces
  domain/                       — JPA entities, value objects
  config/                       — Spring configuration (security, persistence)
  exception/                    — GlobalExceptionHandler, custom exceptions
  mapper/                       — MapStruct entity ↔ DTO mappers (if needed)
```

## Contract Artifact

Group: `com.asms` | Artifact: `asms-api-contract`

The contract artifact provides:
- `com.asms.api.*ApiDelegate` interfaces — implemented by handlers
- `com.asms.api.*ApiController` classes — auto-scanned from the JAR, HTTP only
- `com.asms.model.*Dto` classes — generated OpenAPI model objects

## Testing

- **ArchUnit**: `ArchitectureTest` — layer rules, runs on every build
- **BDD**: Cucumber scenarios in `src/test/resources/features/` — `@Pending` tags = not yet implemented
- **Integration**: `BaseIntegrationTest` + Testcontainers PostgreSQL — real DB, no H2
- **Health check**: `HealthCheckIntegrationTest` — verifies Spring context starts and `/actuator/health` returns UP

Run all tests: `JAVA_HOME=/path/to/java25 mvn test`
